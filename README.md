# designpatterns

A single-file implementation of the Strategy pattern in Go (`strategyPattern.go`),
using the classic duck-behaviour example (quack/fly/eat), written while
following Christopher Okhravi's design patterns video series.

## Status

Written in one sitting in January 2025 as a learning exercise. Not maintained,
and only one pattern is implemented despite the repo name.

## Running it

```
go run strategyPattern.go
```
